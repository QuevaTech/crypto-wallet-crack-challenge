# ⚠️ READ THIS FIRST

Every mnemonic in this repository is **public, forever**. They are demonstration phrases
generated in bulk from a hardware entropy source for a cryptographic experiment.

- **Never** use any phrase from this repository as your wallet.
- **Never** send funds to an address derived from a published phrase: anyone can sweep it
  instantly, and there are bots that scan GitHub for exactly this.
- One single phrase (#1001) is part of the challenge: its first 19 words are published and
  its EVM address is funded with 1 USD. That address is *meant* to be swept by whoever
  recovers the missing five words. It is not a customer wallet.

If you found this repository and thought you discovered leaked seeds: you did not. They were
generated for this challenge, they never held user funds, and they carry no value other than
the prize described in README.md.
